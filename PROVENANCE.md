# Bundled simulator
Source: https://github.com/scalesim-project/scale-sim-v3
Revision: f79d7bc39a80a21fc35bc667967b76a15b311f49
License: MIT; upstream notice retained in vendor/scale-sim-v3/LICENSE.
This repository vendors the simulator, configs, layouts, topologies and Accelergy run directory needed by this lab. It is not an official upstream distribution. Two NumPy reductions and both trace switches are repaired in the distributed source. The equivalent chunked repeated-access counter is included to reduce host runtime. Earlier differential checks covered 108 randomized cases and byte-identical summary reports. The optional WSL energy setup applies additional SRAM-sizing and OFMAP counter corrections. Git is unnecessary for the native Windows path.
